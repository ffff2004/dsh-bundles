### Minor Changes

- dfde0e5: 新增「设置 → Codex 额度」页面，复用 Codex CLI 当前账号的凭据，查看套餐、账号邮箱、各额度窗口的剩余比例与重置时间，以及可用的重置券，无需另外登录。
